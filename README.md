# S&M Marketplace — Customer Version

Customer-facing MVP based on the supplied S&M Marketplace brief.

Included:
- Responsive storefront
- Category browsing: All, Kurtas, Salwar Suits, Sarees, Accessories
- Search and sorting
- Product cards and cart
- WhatsApp checkout handoff
- Order tracking UI
- Wholesale/bulk enquiry UI
- Nepal-focused messaging: free delivery over NPR 5,000 and cash on delivery
- Mobile responsive layout

The supplied brief specifies the customer navigation, hero, shop, order tracking, wholesale section, footer and WhatsApp contact. Product data, real WhatsApp number, inventory, payment gateway, customer accounts and order database were not supplied, so those remain integration points.

Deployment:
1. Connect this GitHub repository to Vercel.
2. Set the production WhatsApp number in app.js.
3. Replace demo product data with the real catalog.
4. Add database/order APIs and payment gateway before taking automated online payments.

Source brief: S&M Marketplace.
